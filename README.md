📝 Shopping List App

A simple shopping list web app built with Vanilla JavaScript, Material Icons (CDN), and Local Storage.
You can add items, adjust their quantity, delete them, and keep track of the total count. The list is saved automatically in your browser (local storage).

🚀 Features

➕ Add Items with a name

🔄 Increase/Decrease Quantity

❌ Delete Items

📊 Live Total Count

💾 Auto-Save to Local Storage (data persists after refresh)

🖱️ Keyboard Support: Press Enter to add items

⏳ Long Press Events (optional: e.g. hold button for extra actions)
